# Self Improve 2.6.0

## New
- A project soul: put a `soul.md` in your project's folder under `projects/` in the Claude config folder (next to its `memory` folder) and its first 1500 characters join the session start, right after your own soul. It is only read; Self Improve never edits it or sends it to the Soul Bank. Keep secrets out of it.

## Changed
- The default review mode is now `controlled`: low-risk lessons apply themselves, and every skill draft (new, fix or rewrite) still waits in `/learn`. Choose `suggest` in the mod's settings to keep everything waiting. Plugin skills are never edited.
